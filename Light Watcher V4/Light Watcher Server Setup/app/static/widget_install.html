Віджет Light Watcher для iPhone

Світло, тривалість, напруга і смуга графіка на головному екрані та екрані блокування.

  1. Встановіть безкоштовний застосунок Scriptable з App Store.
  2. Відкрийте Scriptable, натисніть «+» і вставте текст нижче.
  3. Назвіть скрипт, наприклад «Світло», і запустіть його один раз кнопкою ▶︎: має з'явитися середній віджет.
  4. На головному екрані натисніть і втримайте порожнє місце → «Редагувати» → «Додати віджет» → Scriptable → малий або середній.
  5. Натисніть на доданий віджет → «Script» → виберіть «Світло».

Екран блокування: натисніть і втримайте екран блокування → «Налаштувати» → «Екран блокування» → віджети → Scriptable. Підходять круглий, прямокутний і рядковий.

iOS сама вирішує, коли оновлювати віджет, зазвичай раз на 10–30 хв. Для миттєвих сповіщень лишається Telegram. Без зв'язку віджет показує останні дані, а через 20 хв — «Немає зв'язку».
